# GitHub 授权

云端 Agent 没有你的 GitHub 账号, 每个都去配令牌既麻烦又危险。管理员放行后在插件详情里启用, 你只授权一次:

- 令牌加密存在你自己的服务端, 不下发给手机, 也不下发给任何 Agent。
- 清单里声明了 `service:gh.issues` 的插件 (如点子待办) 的 Agent 默认可以用, 其他 Agent 要你在这里手动打开。
- Agent 通过服务端代办: 看 issue, 建 issue, 评论, 关闭, 挂子 issue; 每次操作都留记录。

## 授权方式

1. 在电脑上授权 (推荐): App 给一个码, 在任何登录了 GitHub 的设备上打开 github.com/login/device 输入即可。需要服务端配置 `GH_CLIENT_ID`。
2. 粘贴令牌: fine-grained token, 权限选 Issues 读写, 仓库按需选。

## 仓库范围

GitHub 上授权的仓库是上限, 这里还可以再收窄, 支持快捷规则: 近一年或近 N 天有提交, 全部公开仓库, 全部私有仓库, 另可手动加入或排除单个仓库。

## 停用

停用后 issue 接口与待办同步都停, 令牌保留, 再启用即恢复; 停用时选清除数据会删掉令牌与仓库规则。
