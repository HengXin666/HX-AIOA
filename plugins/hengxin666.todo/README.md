# 点子待办

> 想到什么就往群里丢一句, 剩下的交给 Agent。

## 它做什么

- **收集**: 安装后多出一个 "点子待办" 群。想法, 要做的事, 半句话都行, 直接发。
- **整理**: 你的 Agent 定时读群里的新消息, 把能落地的整理成待办 (标题, 优先级, 来源消息)。
- **分析**: 对 "要不要做" 还没定的点子, 它会引用原消息回一条可行性分析: 值不值得做, 难点, 第一步。
- **展示**: 工作台多一个 "待办" 面板, 勾掉就算完成, Agent 下次整理时能看到。
- **分区与计划** (2.3): 待办可分 "生活 / 开发 / 工作" 等分区, 设截止时间 (看板显示倒计时), 提前提醒 (服务端发系统消息, 手机本地闹钟或通知到点响), 周期重复 (如每月交电费, 完成后自动排下一期), 星标重点 (显示在总览)。App 里可以直接新建和编辑, 不必经过群。

## 一次安装包含

- **群**: "点子待办" (channel `plugin-todo`)
- **Agent**: "整理员", 只能读写这个群和它的待办
- **工作台**: "点子待办", 一个待办面板
- **提示词**: 整理规则, 分析格式, 记忆方式, 见仓库 `plugins/hengxin666.todo/prompt.md`
- **数据**: 待办存在插件数据 (`items` 集合), App 与 Agent 都按版本号写入, 互不覆盖

## 安装后

1. 复制安装后显示的接入语, 发给你的 Agent (Claude Code, Codex 等)。
2. 它会自己拉取专属指令, 报到, 再按建议建一个定时任务 (默认每 2 小时一次)。
3. 往 "点子待办" 群里发第一个想法试试。想立刻整理, 就在群里说 "整理一下"。

## 说明

- Agent 跑在你自己的机器上, 用的是你自己的模型额度; 服务端只存消息和待办。
- 没有新消息时 Agent 不发任何东西, 不刷屏。
- 卸载只去掉 Agent 和面板, 群里的消息和待办都保留, 重装能接上。
- 2.0 起 id 改为 `hengxin666.todo` (旧 id `todo` 仍可用), 群与工作台沿用 `plugin-todo`; 升级时旧待办自动搬进插件数据, Agent 密钥照用, 不用重新接入。
