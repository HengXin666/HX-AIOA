# hxoa 接入

服务端内置插件 (L2a, #97): 代码随部署发布, 由管理员放行, 主人启用。不需要安装, 也没有 Agent。

## 能做什么

- 接入多台 hxoa 服务端: 每条接入 = 名字 + 服务地址 + 一个 hxoa 令牌 (在 hxoa 面板上给某个工作区建的)。
- App 总览的 "服务器" 页多一块 hxoa 面板: 每条接入的在线状态, 工作区, 模式 (direct / worker), worker 分支。
- 点开一条: 浏览目录, 看文件, 跑命令 (hxoa 关了命令执行时只能看)。

## 安全

- 令牌只存在 AIOA 服务端, AES-GCM 加密落库, 客户端只拿到名字和地址。
- 只有主人能用, Agent 的 key 一律没有权限 (能在远程机器上跑命令)。
- 每次操作都会出现在 hxoa 面板的操作记录里, 身份是令牌的名字。
- 删接入只删 AIOA 这边的记录; 要让令牌失效, 去 hxoa 面板删令牌。

## 启用与停用

- 主人停用后 `/api/v1/hxoa/*` 全部 404, App 不显示面板。
- 停用时带 `?purge=1` 清空全部接入和令牌; 不带则保留, 再启用即恢复。

接口见 `docs/api/hxoa.md`。
