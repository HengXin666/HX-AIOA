# hxoa 管理

服务端内置插件 (L2a, #97, #104): 代码随部署发布, 由管理员放行, 主人启用。不需要安装, 也没有 Agent。

把 hxoa 面板搬进 App: 在手机上决定这台机器映射哪些目录, 再一键复制连接提示交给 AI。需要 hxoa 2.4.1+。

## 能做什么

- 接入多台 hxoa: 每条接入 = 名字 + 服务地址 + 一个管理令牌 (在 hxoa 面板 "远程管理" 里建, `hxadm_` 开头)。
- App 总览的 "服务器" 页: 每台 hxoa 的在线状态与版本, 点开看工作区列表 (路径, 命令执行, workers, 在线连接数)。
- 添加工作区: 目录选择器 (面包屑, 上一级, 新建文件夹), 填名字, 开关命令执行与 workers。
- 改名, 改开关, 删除工作区 (要确认)。
- 连接令牌: 新建 (填身份名), 删除, 合并 worker 分支, **复制连接提示** (主要用途)。

## 安全

- 管理令牌只存在 AIOA 服务端, AES-GCM 加密落库, 客户端只拿到名字和地址; 连接令牌的密钥也不下发, 只在复制连接提示时出现。
- 只有主人能用, Agent 的 key 一律没有权限 (管理令牌等于那台机器的远程控制权)。
- hxoa 只开放白名单接口, 不能远程建管理令牌, 改隧道和面板账号; 错误令牌按 IP 锁定, 写操作记进 hxoa 操作记录, 身份是 `管理:<名字>`。
- 删接入只删 AIOA 这边的记录; 要让管理令牌失效, 去 hxoa 面板删。
- #97 旧版存的是工作区令牌, 升级后列表里提示删掉重接。

## 启用与停用

- 主人停用后 `/api/v1/hxoa/*` 全部 404, App 不显示面板。
- 停用时带 `?purge=1` 清空全部接入和令牌; 不带则保留, 再启用即恢复。

接口见 `docs/api/hxoa.md`。
