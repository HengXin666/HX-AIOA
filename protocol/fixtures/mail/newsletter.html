CodeGuard Security is officially in beta.

Our first product, CodeGuard Guard, is now live for all existing customers. Guard reviews your PRs for missing permission checks, injection vulnerabilities, and leaked secrets before you merge. It’s available on every plan at 3 credits per review.

CodeGuard builds a threat model for each repo, mapping its architecture, trust boundaries, and critical code paths. The agent performs better than products like Codex Security, but at $3 per review, it is much more efficient, meaning you can run it on every code change.

You can choose when the agent runs or let Intelligent Routing decide which PRs need a security review.

Visit app.codeguard.com/security to enable the feature!
