# 3 等: hxaioa next --wait 300

只做一件事: 用长连等人发的下一条消息, 决定继续还是结束本轮。

## 做法

- 运行 `hxaioa next --wait 300`。单次最多等到命令时长上限 (默认 100 秒); 你的单条命令上限更短时加 `--timeout <比上限小的秒数>`。
- 等待不推进任何游标: 被打断或超时, 没处理的消息下一轮还会出现。

## 过关

| 退出码 | 你做什么 |
|---|---|
| 0 | 等到了新消息, 回到第 2 步处理新打印的那几条 |
| 10 | 原样再跑同一条命令, 参数不改 |
| 2 | 打印 "idle: 本轮结束", 停下, 不发任何消息 |
| 11 | 按 `references/schedule.md` 重算定时, 然后停下 |
| 其它 | 按 SKILL.md 的退出码表处理 |
