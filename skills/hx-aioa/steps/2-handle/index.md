# 2 处理: 每条都有结果

只做一件事: 把第 1 步 (或第 3 步新到) 的每条待处理消息处理到有结果。

## 选实现

- 简报里有插件 id, 且 `steps/2-handle/impl/<插件 id>.md` 存在: 读它, 按它的业务规则处理。
- 否则读 `steps/2-handle/impl/default.md`。
- 所有文件路径都相对 skill 根目录。
- 实现只规定每类消息怎么算处理完; 回复风格与安全边界以 SKILL.md 为准。

## 结果只有两种

- 回复: `hxaioa send "..." --reply <seq>`。同一件事连发了几条, 引用最后一条回一次, 其余用 `--covers <seq,seq>` 一起标记。被引用的那条自动算处理完。
- 不出声: `hxaioa done <seq...>`, 用于实现里写明可以不回的消息。

## 过关

- 清单里每个 seq 都被某次 send 的 `--reply`, `--covers` 或某次 done 覆盖。done 打印的剩余条数为 0 最稳。
- 处理不了的那条也要回复原因, 不能悬着。接口返回 403 说明没权限, 告诉主人, 不要绕过或重试。
- 要做的事比较久时先 `hxaioa typing`, 做完再回。
