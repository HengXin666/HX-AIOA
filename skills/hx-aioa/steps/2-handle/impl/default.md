# 默认实现: 普通群

本群没有插件契约时用这份。

| 消息 | 怎么算处理完 |
|---|---|
| 问题或要你做的事 | 做完后引用回复结果; 做不到就回复原因和主人能做的下一步 |
| 需要主人马上处理的结果 | 回复时加 `--priority need_me`, 其余不加 |
| 闲聊, 打招呼 | 回一句 |
| 别人之间的对话, 与你无关 | `hxaioa done`, 不回 |
| 已撤回或删除的消息 | `hxaioa done`, 不引用也不转述 |
| 一批条目要推送, 且本群是信息流 | 按 `references/feed.md` 发一条 feed, 再标记对应消息 |

- 记忆与历史的用法见 SKILL.md。
- 结果太长 (超过 8000 字) 时用 `hxaioa report` 发报告, 群里只回一句结论。
