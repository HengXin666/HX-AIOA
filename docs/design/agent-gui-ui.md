# Agent GUI 界面方案 (#126)

架构见 [agent-gui.md](agent-gui.md)。原型图: [3-desktop.svg](agent-gui/3-desktop.svg) (桌面), [4-mobile.svg](agent-gui/4-mobile.svg) (手机)。视觉按 [ui-spec](ui-spec/README.md) 的令牌与容器, 深色取 ChatGPT 配色 (同 [home-spaces](ui-spec/home-spaces.md))。

## 1. 入口

- 安卓 / Web 总览里多一个空间 "编程", 侧栏 "空间" 里可置顶; 空间根页就是会话列表。
- Web 另有整页工作台 `/agent` (桌面宽屏, 以后的桌面端直接是它)。
- 深链: `hxaioa://agent/<主机>/<会话>`, 通知点进来直达会话里那张审批卡。

## 2. 桌面工作台 (宽 >= 1280)

```
┌ 左栏 264 ───────┬ 顶栏 52: 标题 · Agent 实例 · 模型 · 分支   [工作|审批] [右栏] [...] ┐
│ 主机切换 (路线) │                                            ┌ 右栏 400 (可拖宽, 可收起) ┐
│ 搜索            │   时间线 (最宽 768, 居中)                  │ 改动 | 文件 | 终端 | 计划  │
│ + 新会话        │                                            │                            │
│ 需要你 (2)      │                                            │                            │
│ 项目 > 会话     │   审批卡 (贴在输入框上方)                  │                            │
│                 │   输入框                                   │                            │
│ 设置            │   统计条: 上下文 · tok/s · 缓存 · 费用     │                            │
└─────────────────┴────────────────────────────────────────────┴────────────────────────────┘
```

### 2.1 左栏

| 区 | 内容 | 交互 |
| --- | --- | --- |
| 主机切换 | 主机名, 在线点, 路线标签 (本机 / 局域网 / 隧道 / 中继) | 点开切主机; 多主机时会话列表可合并显示 |
| 搜索 | 会话标题与内容 (探针侧搜) | `Ctrl+K` 也能搜 |
| 新会话 | 整宽按钮 | `Shift+点` 在当前项目直接开 |
| 需要你 | 待审批与提问的会话, 红色计数 | 点开直达那张卡 |
| 项目 > 会话 | 按项目分组; 每行: 状态点 (运行蓝, 等你黄, 完成绿, 出错红, 空闲灰), 标题, Agent 图标, 相对时间, 改动 `+n -m` | 右键: 重命名, 交给另一个 Agent, 分叉, 归档, 删除 |
| 底部 | 设置: Agent 实例, 设备, 路线, 审批规则 | |

### 2.2 时间线

- 一轮 = 你的消息 + "工作组" + Agent 的回答。工作组默认折叠成一行: `读 6 个文件 · 改 3 个 · 运行 2 条命令 · 1 分 12 秒`, 运行中自动展开最新一项。
- 工具行按 ACP `ToolKind` 用图标区分 (read, edit, delete, move, search, execute, think, fetch, other); 同一文件连续读写合并为一行 `x N`, 汇总增删。
- 编辑行点开就地显示红绿 diff (语法高亮, 前 40 行, "在右栏打开"); 命令行点开才订阅它的输出 (终端样式, 有界滚动)。
- 思考 (`agent_thought_chunk`) 默认折叠为 "思考了 8 秒", 点开看全文。
- 计划 (`plan`) 是一张勾选清单, 随 Agent 更新实时勾。
- 子 Agent 作为缩进的工作组, 标子 Agent 名; 子 Agent 的审批也出现在父会话里。
- 出错 / 额度用尽: 红条 + 重置时间 + "重试" "换模型"。
- 长对话: 只渲染可视区 (虚拟列表), 往上滚按轮分页加载。

### 2.3 审批卡 (工作模式里)

贴在输入框上方, 不随时间线滚走; 多个时叠成一张写 "还有 n 个"。内容与手机版同一份 (见 [agent-gui.md](agent-gui.md) 5.1), 键盘: `Enter` 允许一次, `Shift+Enter` 总是允许, `Esc` 拒绝; 直接在输入框打字回车 = 拒绝并把这句话带给 Agent。

### 2.4 输入框

| 位置 | 控件 | 来源 |
| --- | --- | --- |
| 上方 | 附件条 (文件, 目录, 图片, 粘贴的长文本) | |
| 左下 | `+` 菜单: 本地文件 / 工作区文件 / 图片 / 历史会话 / 技能 | ACP 内容块 |
| 左下 | 权限模式按钮 (常驻), 文案用 Agent 公布的模式名 | `session/set_mode` |
| 左下 | 模型面板: 上方 Agent 实例网格 (切实例 = 新会话或接力), 下方模型列表 (可搜), 思考深度滑块 | ACP 配置选项 |
| 中间 | `/` 斜杠命令, `$` 技能, `@` 文件 | `available_commands_update` |
| 右下 | 发送; 运行中变为 "停止", 输入框有字时出现 "插话" 与 "排队" | `session/cancel`, steer 视 Agent 能力 |
| 下方统计条 | `上下文 26% · 61 tok/s · 缓存 82% · $0.04`; 悬停卡: 上下文明细, 累计输入 / 输出 / 缓存读写, 本轮用时, 估算标记 | `hx/stats` |

### 2.5 右栏

| 标签 | 内容 |
| --- | --- |
| 改动 | 三段: 本轮改动 / 会话里改过的文件 / 全部未提交; 点文件看并排或统一 diff; 顶部 "提交" "回退到某轮" (checkpoint) |
| 文件 | 文件树 + 预览 (只读, 语法高亮), 点行号插入 `@文件:行` 到输入框 |
| 终端 | 探针 PTY, 多标签, 默认在会话工作目录 (worktree) |
| 计划 | 当前计划与历史计划 |

标签可拖出成浮窗; `Alt+S` 主对话与右栏左右互换; 全屏右栏时主对话收成状态胶囊 (运行 / 等你 / 完成)。

### 2.6 新会话页

居中一句欢迎 + 吸底输入框; 输入框上方一条选择条: 主机 / 项目 (最近目录, 可输路径) / 分支或新 worktree / Agent 实例 / 模型 / 权限模式。第一条消息发出即建会话。

### 2.7 快捷键

`Ctrl+K` 命令面板, `Ctrl+N` 新会话, `Ctrl+.` 停止, `Ctrl+J` 终端, `Ctrl+Shift+A` 权限模式, `Alt+S` 互换, `Ctrl+[` `Ctrl+]` 上下一个会话, `Ctrl+Shift+Y` 只看等你的会话。

## 3. 手机

遵循 ui-spec 的四种容器: 会话页是子页 (盖住底栏), 模型与权限是底部抽屉, 危险确认是对话框。

### 3.1 空间根页 (会话列表)

- 顶部 "需要你": 横向卡片, 每张一个待决定 (Agent, 一句话动作, 风险色), 点开审批卡。
- "进行中": 运行中的会话, 行内进度 (当前工具一行), 上下文占比小环。
- "最近": 按项目分组。
- 右上 `+` 新会话 (底部抽屉: 主机, 项目, Agent 实例, 模型); 标题旁路线标签。

### 3.2 会话页 (工作模式)

- 顶栏: 返回, 标题, 副标题 `Claude Code · Sonnet · 26% · 61 tok/s`, 菜单。
- 分段: 对话 / 改动 / 终端 / 文件 (横滑切换)。
- 对话: 同桌面时间线, 工作组默认折叠更狠 (只露一行); diff 点开进子页。
- 审批卡贴在输入框上方, 大按钮; 键盘上方快捷条: 停止, 插话, 权限, 模型, 附件, 语音。
- 改动: 文件列表 -> 子页统一 diff (可双指缩放, 长行横滑)。
- 终端: xterm (同现有终端), 上方一排 Esc, Tab, Ctrl, 方向键, `|`, `~`。
- 文件: 树 -> 预览。
- 平板 / 横屏 >= 840: 左会话列表, 右会话页; 再宽加右栏。

### 3.3 审批模式

手机默认审批模式, 空间根页换成收件箱 (顶部 "审批 | 工作" 切换, 记在本机):

- 一屏一张卡, 左右滑切下一张; 卡片: 头 (Agent · 项目 · 等了多久 · 还有 n 个), 四问 (动作, 为什么, 影响, 选项), 底部大按钮 "允许一次", 次按钮 "总是允许" "拒绝并说明", 链接 "看全部" (切工作模式定位到这一项)。
- 高风险: 主按钮改为长按 1 秒确认, 红色描边。
- 卡片下方 "进行中" 状态带: 每个会话一行 (状态点, 标题, 当前在干什么, 上下文占比)。
- 关键时刻卡: 一轮做完 (总结, 改动, 用时, token, 缓存命中; 快捷回复 "继续" "跑测试" "提交" "说点什么"), 计划待批, 提问 (选项 + 语音输入), 出错, 上下文过 80% ("压缩" 若 Agent 公布了该命令)。
- 通知: 低风险带 "允许一次" "拒绝" 两个按钮; 中高风险只能点进来; 其它端答了, 通知自动消失。电脑前正看着这个会话时, 手机默认只发静默通知 (60 秒没人答再正常推一次)。
- 设置 (存在探针本地, 经直连读写): Agent 实例, 风险规则, 电脑前看着时手机 (静默推送 / 不推 / 正常推送), 路线与隧道地址, 已配对设备。

## 4. 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 路线 | 顶栏小标签: 本机 / 局域网 / 隧道 / 中继; 中继时提示 "正在用中继, 会消耗 CF 额度" |
| 连接断开 | 顶部细条 "重连中", 内容保持可读但标记为旧; 恢复后按 seq 补, 不闪 |
| Agent 启动中 | 显示 ACP 报的启动阶段 (若有), 不用假进度 |
| 等你 | 黄点 + 侧栏 "需要你" 计数 + 页标题前加 `(1)` |
| 额度用尽 | 红条 + 重置时间 |
