# 新总览: 侧栏, 空间切换与插件入口 (#121)

整体按 Telegram 的结构: 左侧栏 + 会话页, 没有底部五栏, 打开 App 默认进总览。视觉参考 ChatGPT 深色 (侧栏推开内容, 顶栏圆钮与标题胶囊), 切换参考 Telegram X 文件夹, 右上菜单参考 QQ "+"。实现在组件库 `kit/HomeShell.kt` `kit/HomeSidebar.kt`, 画廊页 "新总览" (`gallery/HomeDemo.kt`), 截图 `./gradlew :gallery:homeShots -PdesktopOnly=true`。

## 1. 骨架

```
┌ ≡   日常 ⌄            (⋯) ┐  顶栏: 侧栏 / 当前空间 (点开切换) / 菜单
│ [日常 2] 开发 3  服务器  点子待办 5 │  置顶空间横排 (最多 5 个)
│                                    │
│  空间内容: 分组标题 + 平铺行         │
│                                    │
└────────────────────────────────────┘  没有底部输入, 输入框只在会话页
```

- 侧栏在内容下面, 打开时把内容推向右边并压暗 (ChatGPT 做法), 不是盖住。任意位置横向拖动开合, 松手按速度或过半决定, 弹簧阻尼 0.92 不回弹; 点被推开的内容收起。
- 不用 M3 那套异形 / 圆形强调: 除头像外, 图标底, 按钮, 输入条, 菜单都是圆角矩形 (10 / 12 / 16 / 22)。
- 颜色全部来自 HX-UI ink 皮肤 (见 hx-ui-sync.md): 深色内容 #000000, 卡片 / 控件 #212121, 侧栏 #0D0D0D, 描边 #373737, 推开遮罩 #616161。

## 2. 三处切换, 各管各的

| 入口 | 放什么 | 交互 |
| --- | --- | --- |
| 置顶横排 | 置顶的空间, 最多 5 个 | 点按切换; 数字是未处理数 |
| 顶部标题 ⌄ | 全部空间 (含插件的), 当前项打勾, 底部 "管理空间与排序" | 弹出菜单, 选中即切 |
| 侧栏 "空间" | 置顶的空间 + "更多空间 (n)"; 右上 "编辑" 进管理页 | 同时也是去消息, Agent, 资源的地方 |

管理页: 拖动排序, 开关置顶, 隐藏; 设置跟账号走 (服务端存), 换手机不丢。

现状 (安卓, #139): 管理抽屉用上移 / 下移排序; 顶部标签最多 5 个, 按 §3 规则 1 分配: 用户置顶的优先, 空位按优先级自动补。每行标出 "置顶" (用户设的), "自动" (空位补上的), "更多空间"; 手动置顶会挤掉自动补位的, 5 个都是用户置顶的才提示 "先取消一个"; 底部 "恢复默认" 清掉顺序与全部置顶设置 (隐藏不动)。设置都跟账号走: 插件空间的置顶与隐藏走 `PUT spaces/{id}/state` 的 `pinned` / `hidden` (`null` 清掉); 内置页面 (消息, 工作区, 开发, 服务器) 不是服务端空间, 它们的置顶与整体顺序存账号设置 `homeTabs` (`{ order, pins }`, 随已有的设置拉取与 `settings` 帧同步, 不多发请求), 本机留缓存作离线兜底, 旧版存在本机的值第一次连上时迁上去。

## 3. 空间与插件

两种贡献, 宿主负责摆放, 插件不能自己画页面框架:

| 贡献 | 插件声明 | 出现在 |
| --- | --- | --- |
| 空间 (space) | `spaces: [{ id, title, icon, hint }]`, 现为清单 `space` (可带 `tab`) | 标题切换菜单, 侧栏; 有空位按 `tab` 自动进横排, 或用户置顶 |
| 区块 (section) | `sections: [{ space, id, title, order }]` | 指定空间里的一个分组 (标题 + 行), 例: hxoa 插件往 "工作区" 加 "hxoa" 分组 |

规则:

1. 顶部标签最多 5 个, 显示顺序永远按用户排的顺序, 名额这样分:
   - 用户设过的永远按用户的: 总览固定第 1 位; 设了置顶的按显示顺序先占名额, 超出的进 "更多空间"; 设了不置顶的不会被自动补上。
   - 剩下的名额给没设过的, 按优先级补: 消息 > 插件声明 `tab: "primary"` 的空间 > 其它内置页 (工作区, 开发, 服务器, 按默认顺序) > 插件 `tab: "auto"` (缺省, 按安装顺序)。`tab: "none"` 的插件从不自动置顶, 用户仍可手动置顶。隐藏的不置顶。
   - `primary` 只给可信来源 (官方源与主人私有源), 第三方源, 开发模式, Agent 下发的空间由服务端降为 `auto`。
   - 结果: 默认是 总览, 消息, 工作区, 开发, 点子待办 (`primary`), 服务器进 "更多空间"。
2. 插件的区块默认排在该空间最后, 用户可在管理页拖动, 可隐藏。
3. 区块只能用组件库的行与分组 (`Item` / 分组标题 / 动作按钮), 统一样子; 要别的样子写主题或组件插件替换。
4. 插件来的空间在切换菜单和侧栏标 "插件"; 卸载插件, 它的空间和区块一起消失, 用户的排序记录保留以便重装。
5. 数字 (未处理数) 由空间或区块上报, 横排和侧栏只显示, 不自己算。
6. 图标 (#142): 管理页里点行首图标可换, 内置页面与插件空间都能换; 从组件库图标集选 (英文名或中文关键词搜), 或上传 PNG / JPEG / WebP / SVG。上传复用头像接口 (内容哈希, ≤64KB), 位图缩成 96px PNG, SVG 只在本机光栅化 (只画基本图形, 不上传原文); 只用 currentColor / 黑色的 SVG 存成 `svg:<id>` 跟主题着色, 其余 `img:<id>` 原色。存储: 插件空间 `state.icon`, 内置页面 `homeTabs.icons`, 随已有的拉取同步, 0 额外请求; "恢复默认" (顺序与置顶) 不动图标。

归类 (#144): "工作区" 就是 agent harness 的家, 放 agent harness 任务 (等待确认 / 进行中 / 已结束), 接入的电脑, 以及 hxoa 的工作区, worker 与连接令牌; "服务器" 只放服务器资源 (主机探针与指标, 添加主机, CF 额度); GitHub 只在 "开发" 页 (#152)。

现状 (安卓, #142 #144): 区块还没有通用声明, hxoa 插件 (`hengxin666.hxoa`, 主人私有源) 的 "hxoa" 分组由宿主写在 "工作区" 页最后 (#142 时放在 "服务器", #144 归回工作区), 主人启用了才出现 (以 `/api/v1/hxoa` 是否 404 / 403 为准, 本机记住结果, plugin_update 时重查); 侧栏同时多一个 "hxoa" 入口, 点了切到 "工作区" 并打开列表页。点开是一层全屏页 + 页面栈: 全部 hxoa → 一台 (工作区列表) → 工作区 (执行命令 / workers 开关, 连接令牌) 或添加工作区 (选目录)。

## 4. 右上角菜单 (⋯)

只放动作, 不放入口 (入口都在侧栏, 避免两处重复): 记个点子, 新建群聊, 扫码 / 加入, 接入 Agent; 分隔线下 "编辑这个空间"; 再下面是 "插件快捷动作", 最多 3 个, 右边写来自哪个插件。账号与连接状态放侧栏头部。

## 设计稿 (2026-11-27)

画廊 `HomeDemo` 的真实渲染, 组件在 `kit/HomeBlocks.kt` (概况, 数字格, 分组, 行, 标签, 进度, 勾选框):

- 圆形只用在头像, 右上角菜单钮和状态小点; 其余一律圆角矩形。
