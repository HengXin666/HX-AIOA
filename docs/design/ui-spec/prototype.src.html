导航

  • 页面里的跳转用 go (记来源), 点底栏用 select (清来源)。再点当前栏: 回到栏根页并滚到顶。
  • 任何页面都有深链 hxaioa://页面 id, 通知, 横幅, 分享进来都走同一个入口, 返回链路与手点一致。
  • 支持预测性返回 (manifest 开 enableOnBackInvokedCallback), 子页跟手滑出, 抽屉跟手下沉。
  • 宽屏 ≥ 840dp: 左侧导航栏, 列表 + 详情双栏; 子页在右栏打开, 不推整屏。

    • 反馈与状态

  • 加载 / 空 / 错误三态顺序固定: 有缓存先显示缓存 + 顶部细进度; 无缓存骨架屏; 空态一句话 + 一个动作; 错误按类型给 "重试 / 去设置"。
  • 提示统一底部 Snackbar (离底栏 16), 删除类操作带 "撤销" 5 秒, 不再弹 Toast。
  • 危险操作: 可撤销的直接做 + 撤销; 不可撤销的才用对话框确认, 主按钮红色并写清后果。
  • 未保存修改: 返回先问 "放弃修改?"。
  • 实时: 秒级数据旁边放绿点; 断线时全局顶部出现 "正在重连" 条, 实时数据变灰并显示 "更新于 x 前"。

    • 手势与触控

  • 点按区域 ≥ 48dp; 行高 52 (双行 60); 列表行可左滑出操作 (已读, 免打扰, 删除)。
  • 下拉刷新只放在 "进页拉取" 的页面; 秒级推送的页面不放。
  • 动效时长 150 / 250 / 500, 缓动 ease-out (0.22, 1, 0.36, 1); 系统开了减弱动效就只淡入淡出。

    • 插件替换

  • 所有页面只能用组件库 (client/android/ui) 里的容器与组件, 不直接用 material3 的 AlertDialog / ModalBottomSheet / Toast。
  • 主题插件 (core.theme.base) 只换令牌; 要换整个组件, 写插件注册到对应扩展点, 并通过同一组截图检查。
