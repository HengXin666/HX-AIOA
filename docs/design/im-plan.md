# 消息 (IM) 改造计划

目标: 把 "消息" 做成自部署的企业微信 / Telegram 式体验: 本地库为准, 秒开, 增量, 实时。

## 模型

- 群 = 事件的 `channel` (推送方决定); 没写按来源名; 本人设备发的归 "备忘"。
- 组 = 客户端把几个群收在一起, 存账号设置 `chatFolders`, 多端同步, 服务端不关心。
- 消息唯一标识 = 服务端 `seq` (单调递增), 客户端一切缓存以它为键。

## 阶段

### P0 修复与美化 (已完成)

- 修进群白屏: 列表键改用 `seq` (原来时间分隔按时间戳做键, 来源时间乱序时会重复导致崩溃); 打开群时去重合并。
- 聊天页重做: 倒序 LazyColumn (新消息不用滚动, 自带插入动画), 连续消息合并成串, 日期胶囊, 时间放气泡内, 字母头像按名字固定配色, 长按菜单 (先有复制)。
- Markdown: 自带轻量解析 (段落, 标题, 引用, 列表, 代码块, 行内代码, 粗斜删除, 链接, 裸链接), 按文本缓存解析结果; 群列表摘要去掉标记。
- 崩溃记录: 崩溃时写本地, 下次连上后作为备忘发出, 便于排查。

### P1 引用, 收藏, 转发 (已完成)

- 消息体加 `reply`: `{ seq, src, excerpt }`。引用时把被引用消息的摘要快照一起存进新消息 (原消息被清理后引用仍可显示), 点击按 `seq` 跳转, 本地没有则按需拉取 `GET /api/v1/events/{seq}`。
- 收藏: 每个账号一张 `fav` 表 `(seq PK, ts, saved, body 快照)`; `GET /api/v1/favorites?since=` 增量, `PUT/DELETE /api/v1/favorites/{seq}`; 本地镜像一张表, 乐观更新。
- 转发: `POST /api/v1/messages/forward { seqs, to: channel | "memo" }`, 新消息带 `fwd: { src, ts }` 快照; 多选转发合并成一条。
- WS `send` 帧支持 `reply` 与 `channel`, 让各群也能发言 (发到群里由该群的 agent / 来源处理, 先只落库)。

### P2 头像与群资料 (已完成)

- `chats` 表: `channel PK, title, avatar, muted, pinned, updated`; `GET /api/v1/chats?since=` 增量, `PATCH /api/v1/chats/{channel}`。
- 头像: 客户端裁成 256px WebP 上传 `PUT /api/v1/avatars` (≤64KB, 存 DO SQLite), 返回内容哈希 id; `GET /api/v1/avatars/{id}` 带 `Cache-Control: immutable`, 客户端按 id 永久磁盘缓存。本人头像存在用户资料里。
- 置顶, 免打扰随群资料同步。

### P3 缓存优先, 增量动画 (已完成: 群, 收藏, GitHub, 数据源, 账号设置走 ApiCache; 列表项 animateItem)

- 通用 `CachedResource`: 页面打开先读磁盘缓存立刻显示, 后台带 `If-None-Match` 刷新, 304 不动, 有变化只替换变化的项 (按稳定键 diff), 列表项用 `animateItem` 过渡。
- GitHub, 数据源, 资源, Agent 等页面全部改走它; 服务端 GET 接口统一返回 `ETag`。
- 状态持有者 (State 类) 跟随 ViewModel 存活, 切栏不重建; 只有首次或缓存过期才转圈。

### P4 性能与实时 (已完成: 分页, 乐观上屏与重发, 已读同步, 引用跳转)

- 消息分页: 打开群只读最近一页, 上滑按 `seq` 向前翻页; 跳到引用时按需加载附近一段。
- 发送乐观上屏: 本地先插一条 `pending` (以 `cid` 为键), 收到 `sent` 帧后换成正式 `seq`, 失败可重发。
- 断线补齐: 重连带 `since=本地最大 seq` (已有), 群列表摘要由本地库增量维护, 不整表重算。
- 已读多端同步: 每群已读位置存服务端, 其它设备收到后更新未读数。

### P5 群内 Agent (已完成)

- 可以新建群 (只建资料, 没消息也显示)。
- 每个群可接多个 Agent: 接入时服务端新建来源 (默认发到本群) 与专用 key, 返回完整接入提示词, 一键复制。
- 使唤提示词存服务端; Agent 挂了点 "重新接入" 作废旧 key 拿新提示词。
- 可授权 Agent 读别的群 (`events:read` + 群白名单), 用来做精选; 群可标成日报 / 周报, 长按消息可 "收录" 进去。
- 免打扰的群照常收消息但不响铃 (:link 进程读 muted-groups.txt)。
- 接口见 `docs/api/chat.md`。

## 验收

- 进任意群不崩, 千条消息滚动不掉帧。
- 页面二次打开无转圈, 数据变化有插入 / 更新动画。
- 引用, 收藏, 转发在另一台设备上同步可见。
