# 安卓 "我的" 与设置页功能对照

本次重做只改界面, 功能不变。旧版有两处入口: "我的" 页 (外观, 数据源, 进入设置, 更新公告) 和一个整屏的 "设置" 页 (所有连接, 代理, 更新, 权限, 日志, 关于挤在一列)。新版合并为 "我的" 一处: 根页是账号卡 + 分组列表, 每项一个独立子页, 子页有标题栏和返回箭头, 返回键逐级回到列表。

## 新结构

```
我的 (根页)
├─ 账号卡: App 图标 about_art, 服务端域名, 在线状态点 → 服务端
├─ 数据: 数据源, 工作台与组件 (跳到 "资源" 页)
├─ 连接: 服务端, 代理, 连接日志
├─ 通知: 通知设置
├─ 外观: 外观
├─ 系统: 系统权限, 更新
└─ 关于
```

- 手机: 单栏, 子页从右侧滑入, 返回滑出。
- 宽屏 (可用宽度 ≥ 720dp): 左列表右详情, 右侧默认显示 "关于", 详情切换淡入淡出。
- 首次启动未配置时: 单独的 "连接服务端" 页 (地址, 令牌, 订阅, 长连接走代理开关, 保存并连接), 保存后进入主界面。

## 旧位置 → 新位置

| 功能 | 旧位置 | 新位置 |
| --- | --- | --- |
| 服务端地址, 令牌 | 设置页 · 服务端 | 我的 → 服务端 (输入行, 令牌可显示/隐藏); 首次配置页 |
| 保存并连接 (校验非空, 重载长连接) | 设置页 · 订阅代理下的按钮 | 服务端页 "保存并连接"; 代理页 "保存并应用" (同一保存逻辑) |
| 连接状态 | 无 (只在消息页) | 账号卡状态点 + 服务端页 "状态" 组 |
| 订阅链接 | 设置页 · 订阅代理 | 我的 → 代理 → 订阅 |
| 消息长连接也走代理 (开关) | 设置页 · 订阅代理 | 我的 → 代理 → 订阅 (Switch 行) |
| 代理摘要, 订阅状态, 内核报错, 操作提示 | 设置页 · 订阅代理 | 我的 → 代理 → 状态 |
| 立即优选节点, 重新下载订阅, 刷新 | 设置页 · 订阅代理 (一行三个按钮) | 我的 → 代理 → 操作 (三行) |
| 节点列表 (点选切换, 最多 30 个, 延迟, 类型, 剩余数) | 设置页 · 订阅代理 | 我的 → 代理 → 节点 |
| 连接日志 (计数摘要 + 记录) | 设置页 · 连接日志 | 我的 → 连接日志 (新增本页刷新按钮) |
| 当前版本, 更新下载路由 | 设置页 · 更新 | 我的 → 更新 → 版本 |
| 检查更新与进度文字 | 设置页 · 更新 | 我的 → 更新 |
| 待安装版本说明 | 设置页 · 更新 | 我的 → 更新 (单独一组) |
| 历史更新公告 (抽屉) | 我的 · 版本与更新公告 | 我的 → 更新 → 更新说明 |
| 通知引导文字 (MIUI 悬浮, 锁屏) + 消息通知设置 | 设置页 · 系统权限 | 我的 → 通知设置 → 渠道 |
| 通知权限状态 | 无 | 我的 → 通知设置 → 状态 (新增, 只读) |
| 测试通知 | 无 | 我的 → 通知设置 → 测试 (新增, 不改 Notifier, 单独 id) |
| 电池优化白名单 | 设置页 · 系统权限 | 我的 → 系统权限 → 后台保活 (显示是否已加入) |
| 自启动设置 | 设置页 · 系统权限 | 我的 → 系统权限 → 后台保活 |
| 安装未知应用 | 无 (只在更新时弹) | 我的 → 系统权限 → 安装 (新增入口, 复用 InstallPermission) |
| 明暗 (跟随系统, 浅色, 深色) | 我的 · 外观 (Chip) | 我的 → 外观 → 明暗 (单选行) |
| 主题色, 圆角, 密度, 恢复默认 | 我的 · 外观 | 我的 → 外观 → 样式 (组件库 AppearanceEditor) |
| 数据源 | 我的 · 接入 | 我的 → 数据 → 数据源 (原 SourcesPage, 内部逐级返回不变) |
| 工作台 | 资源页 | 资源页不变; 我的 → 数据 → 工作台与组件 作为入口 |
| 关于: App 图片, 名称版本, 简介, 仓库 | 设置页 · 关于 | 我的 → 关于 |
| 规则 | 无 | 暂无此功能, 未加入口 |

## 实现说明

- 代码在 `client/android/app/src/main/java/com/hengxin/aioa/ui/settings/`, 独立包, 避免与 `ui` 包内顶层名字冲突。
- `SettingsModel` 未改。它在创建时会按需拉起代理内核, 所以根页摘要只读本机配置与系统状态, 只有进入服务端, 代理, 连接日志, 更新子页时才创建它, 与旧版 "打开设置页才创建" 一致。
- 系统权限与通知状态在每次回到前台时重读, 从系统设置页回来即可看到新状态。
- 旧 `MePage.kt` 删除; `SettingsScreen.kt` 只保留首次配置页和 `SystemActions`; `Shell.kt` 只把 "我的" 换成新导航; `MainActivity.kt` 去掉整屏设置页分支, 把 `SettingsModel` (延迟) 与系统动作传给 `Shell`。
