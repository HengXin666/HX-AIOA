# 安卓端返回路径

返回键 (含手势返回) 一律 "退一级, 回到你来的地方"。这份表是全部入口的清单, 加新页面或新跳转时同步改这里, 并在 `app/src/test/.../TabNavTest.kt` 补用例。

## 三层, 从里到外

返回键先给最里层, 里层没东西可退时才交给外层。Compose 里后注册的 `BackHandler` 先收到, 所以子页的处理天然优先于外层。

1. 弹层: `Dialog` / `ModalBottomSheet` 自带返回 = 关闭。例: 过渡层 FeedPeek, Agent 详情, 接入向导, 终端, 单封邮件 MailPeek, hxoa 管理各页。
2. 栏内子页: 用状态切换整页的 (群, 群设置, 收藏, 我的 → 子设置页, 插件详情, 数据源添加, 邮件详情, GitHub 叠层), 在切换的同一处挂 `BackHandler`, 只退一级。
3. 栏: `Shell` 用 `TabNav` 管当前栏和跨栏跳转的来源。返回: 有来源回来源, 没有回总览, 总览再交给系统退出。

## 规则

- 改当前栏只用 `nav.select` (点底部栏, 清空来源) 和 `nav.go` (页面里的链接, 记下来源); 不要直接改 tab。
- 页面里的跳转要用 `go`, 不要用 `select`, 否则返回会回总览而不是来源。
- `BackHandler` 只在 "自己这层还有东西可退" 时 `enabled`; 退到这层的根页就关掉, 交给外层。不要写 `BackHandler { if (!x.back()) onBack() }` 这种自己兜到底的, 外层另有处理时会退两级或在宽屏上跳到别的页。
- 全屏的子页 (状态切整页) 必须有返回处理; 一眼看不出时用 `Dialog` / `ModalBottomSheet`。
- 跨栏跳进别的栏的子页 (如 GitHub 空状态 → 我的 → 数据源), 子页返回回来源, 不回那个栏的列表。

## 入口清单

| 从 | 操作 | 到 | 返回到 |
| --- | --- | --- | --- |
| 任意栏 | 点底部栏 | 该栏 | 总览 |
| 总览 | 任务卡片 / 资源卡片 / 告警 | Agent / 资源 / 消息 | 总览 |
| 总览 | 点一条邮件 | 单封邮件 (不进群, 只标这一封已读) | 总览 |
| 总览 | 点其它条目 → 去消息里看 | 所在群, 定位到该条 | 群列表 → 总览 |
| 总览 / 资源 | GitHub | GitHub 叠层 → 仓库 | 逐级回到打开它的栏 |
| GitHub 空状态 | 添加数据源 | 我的 → 数据源 → 添加 | 添加 → 数据源列表 → GitHub 叠层 (原栏) |
| 我的 | 工作台与组件 | 资源 | 我的 |
| 我的 | 任一子页 | 子页 (插件 → 详情, 数据源 → 添加 / 结果) | 逐级回到我的列表 → 总览 |
| 任意栏 | 新消息横幅 | 消息 → 该群 | 群列表 → 原来的栏 |
| 消息 | 群 → 群设置 / 收藏 | 子页 | 群 / 群列表 |
| 收藏 | 定位 | 所在群 | 群列表 |
| 邮件群 | 筛选 / 厂商 / 点开一封 | 筛选态 / 详情 | 详情 → 列表 → 清筛选 → 群列表 |
| 信息流 | 点卡片或链接 | 过渡层 FeedPeek | 关闭过渡层 |
| 资源 (服务器页) | hxoa 面板 → 一台 hxoa → 工作区 / 添加工作区 | 全屏 Dialog 逐层叠 | 逐层关闭 → 服务器页 |

宽屏 (左列表右详情) 的 "我的": 列表一直在, 子页根部的返回交给外层 (回来源栏或总览), 不把右侧换成 "关于"。

## 怎么查

- 单测: `gradle :app:testDebugUnitTest` 跑 `TabNavTest` (栏与来源的规则), CI 安卓构建里也会跑。
- 评审时对着上面的清单, 每条走一遍 "进去 → 返回"; 新增跳转没进清单或没补用例的, 不合并。
- 搜一遍 `BackHandler` 和 "用状态切整页" 的写法 (`if (x != null) { ...; return }`), 看每处是否只退一级。
