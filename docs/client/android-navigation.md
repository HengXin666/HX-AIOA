# 安卓端返回路径

返回键 (含手势返回) 一律 "退一级, 回到你来的地方"。这份表是全部入口的清单, 加新页面或新跳转时同步改这里, 并在 `app/src/test/.../TabNavTest.kt` 补用例, 同时改 `docs/design/ui-spec/pages.json` 并运行 `gen.py` 更新页面关系图与原型 (规范见 `docs/design/ui-spec/README.md`, #121)。

## 三层, 从里到外

返回键先给最里层, 里层没东西可退时才交给外层。Compose 里后注册的 `BackHandler` 先收到, 所以子页的处理天然优先于外层。

1. 弹层: `Dialog` / `ModalBottomSheet` 自带返回 = 关闭。例: 过渡层 FeedPeek, 接入向导, 查看指令, 终端, 单封邮件 MailPeek, hxoa 管理各页, 消息列表的域 (全屏 Dialog), 合并转发的聊天记录, 资料卡, 长按消息的操作条, 长按群的操作抽屉。
2. 栏内子页: 用状态切换整页的 (群, 群里的多选 (返回先退出多选), 群设置, 群设置里叠的子页 (`GsStack`: 成员与群 Agent, 群 Agent 设置, 查找记录, 群文件, 精选), 收藏, 我的 → 子设置页, 插件详情, 数据源添加, 邮件详情, GitHub 叠层), 在切换的同一处挂 `BackHandler`, 只退一级。
3. 栏: `Shell` 用 `TabNav` 管当前栏和跨栏跳转的来源。返回: 有来源回来源, 没有回总览, 总览再交给系统退出。

## 规则

- 改当前栏只用 `nav.select` (点顶部标签或底部栏, 清空来源) 和 `nav.go` (页面里的链接, 记下来源); 不要直接改 tab。
- 页面里的跳转要用 `go`, 不要用 `select`, 否则返回会回总览而不是来源。
- `BackHandler` 只在 "自己这层还有东西可退" 时 `enabled`; 退到这层的根页就关掉, 交给外层。不要写 `BackHandler { if (!x.back()) onBack() }` 这种自己兜到底的, 外层另有处理时会退两级或在宽屏上跳到别的页。
- 全屏的子页 (状态切整页) 必须有返回处理; 一眼看不出时用 `Dialog` / `ModalBottomSheet`。
- 跨栏跳进别的栏的子页 (如 GitHub 空状态 → 我的 → 数据源), 子页返回回来源, 不回那个栏的列表。

## 入口清单

| 从 | 操作 | 到 | 返回到 |
| --- | --- | --- | --- |
| 任意栏 | 点顶部标签 (新外壳) / 底部栏 (旧外壳, 平板左侧导航) | 该栏 | 总览 |
| 任意一级页面 | 顶部标签 / 侧栏 "空间": 开发, 服务器, 插件空间 (点子待办, HX OA...) | 总览栏的对应看板 (不是新栏) | 总览 (日常) → 退出 |
| 任意栏 | 侧栏: 收藏, GitHub, 我的, 最近会话 | 收藏页 / GitHub 叠层 / 我的 / 该群 | 来源栏 (侧栏先收起); 收藏与最近会话按一次就回来源栏, 不经过群列表 (`Shell` 的 `sideReturn`) |
| 任意栏 | 侧栏搜索框 → 点群 / 点消息 | 搜索页 (全屏 Dialog) → 该群 / 该群定位到那条 | 搜索页返回关闭; 进群后同上, 一次回来源栏 |
| 总览 | 任务卡片 / 资源卡片 / 告警 | agent harness / 资源 / 消息 | 总览 |
| 总览 | 点一条邮件 | 单封邮件 (不进群, 只标这一封已读) | 总览 |
| 总览 | 点其它条目 → 去消息里看 | 所在群, 定位到该条 | 群列表 → 总览 |
| 总览 / 资源 | GitHub | GitHub 叠层 → 仓库 | 逐级回到打开它的栏 |
| GitHub 空状态 | 添加数据源 | 我的 → 数据源 → 添加 | 添加 → 数据源列表 → GitHub 叠层 (原栏) |
| 我的 | 工作台与组件 | 资源 | 我的 |
| 我的 (连接) / 内置浏览器菜单 | 网站与登录 | 网站与登录 (独立 Activity, 浏览器进入时当前站点置顶) | 来源 (我的 / 浏览器); 点一行打开该站并关掉本页 |
| 我的 | 任一子页 | 子页 (插件 → 详情, 数据源 → 添加 / 结果) | 逐级回到我的列表 → 总览 |
| 任意栏 | 新消息横幅 | 消息 → 该群 | 群列表 → 原来的栏 |
| 消息 | 群 → 群设置 / 收藏 | 子页 | 群 / 群列表 |
| 消息列表 | 点域 | 域 (全屏 Dialog) | 群列表; 从域进群, 退出群回到域 |
| 群 | 点头像 → 资料卡 → 发消息 | 单聊 (同一栏, 不记路径) | 群列表 |
| 群 | 资料卡 (群 Agent) → 群 Agent 设置 | 群设置里的该群 Agent | 群设置 → 群 |
| 群 | 点合并转发卡片 | 聊天记录 (全屏 Dialog, 只读) | 群 |
| 群 | 长按消息 → 多选 | 多选 (顶栏 "已选 n 条") | 群 |
| 群聊设置 | 成员 "全部" / 群 Agent 行 / 查找记录 / 群文件 / 精选 | 叠在群聊设置里的子页 | 逐级回群聊设置 → 群 |
| 成员与群 Agent | 群 Agent 标签点一条 | 群 Agent 设置 | 成员与群 Agent → 群聊设置 |
| 群聊设置 | 收藏 | 收藏页 | 群聊设置 |
| 查找记录 / 群文件 / 群 Agent 设置的记录 | 点一条 | 所在群, 定位到该条 | 群列表 |
| 新外壳顶栏 | 点标题选 总览 / 开发 / 服务器 / 插件空间 | 总览栏的对应看板 (不是新栏) | 同上 |
| 宽屏 (平板左侧导航) | 总览的开发 / 服务器 / 插件看板 | 同一栏 | 先回日常看板, 再交给系统退出 |
| 收藏 | 定位 | 所在群 | 群列表 |
| 邮件群 | 筛选 / 厂商 / 点开一封 | 筛选态 / 详情 | 详情 → 列表 → 清筛选 → 群列表 |
| 信息流 | 点卡片或链接 | 过渡层 FeedPeek | 关闭过渡层 |
| 工作区 (agent harness) / 侧栏 hxoa | hxoa 分组 → 一台 hxoa → 工作区 / 添加工作区 | 全屏页 + 页面栈 (#142) | 逐层退 → 工作区页 |
| 总览 | 重点待办卡片 / 点子待办 "打开看板" | 全部待办看板 (全屏 Dialog), 详情与编辑是底部弹层 | 弹层 → 看板 → 总览; 详情里 "来源消息" 进所在群 |
| 消息 | 待办群 → 待办 → 本群 / 全部 | 看板 (同一页切换) | 详情弹层 → 看板 → 聊天 |
| 更多空间 / 侧栏 "网盘" | 网盘 → 子文件夹 / 搜索 / 回收站 / 我的分享 | 总览栏的网盘看板, 目录与子页用状态切换 (#154) | 子页 / 搜索 → 文件列表; 子文件夹逐级 → 根 → 总览 (日常) |
| 群 | 长按文件消息 → 存到网盘 | 不跳转 (提示存到哪) | - |

新外壳的左侧栏: 只在一级页面 (外壳顶栏和顶部标签在显示时, `HomeFrame` 的 `bars`) 能横划拉出, 子页 (群, 群设置及其叠层, 收藏, 域, 聊天记录, GitHub 叠层, 我的, 全屏 Dialog) 里划不出; 拉到一半松手按速度或过半吸附到开或关。侧栏开着时返回键先关侧栏。一级页面左缘竖直居中的一段 (宽 32dp, 高 200dp, 系统每条边最多认 200dp) 做了系统手势排除, 在那里右划是拉侧栏, 不会触发系统返回退出 App; 其余位置的左缘仍是系统返回。

宽屏 (左列表右详情) 的 "我的": 列表一直在, 子页根部的返回交给外层 (回来源栏或总览), 不把右侧换成 "关于"。

## 怎么查

- 单测: `gradle :app:testDebugUnitTest` 跑 `TabNavTest` (栏与来源的规则), CI 安卓构建里也会跑。
- 评审时对着上面的清单, 每条走一遍 "进去 → 返回"; 新增跳转没进清单或没补用例的, 不合并。
- 搜一遍 `BackHandler` 和 "用状态切整页" 的写法 (`if (x != null) { ...; return }`), 看每处是否只退一级。
